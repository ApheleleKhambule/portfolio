# Aphelele Khambule — Portfolio Website

My personal portfolio: who I am, my skills, projects, experience, education, certifications and how to contact me.

**Live site:** https://ApheleleKhambule.github.io/portfolio

## Built with

- **HTML** — semantic structure (`header`, `nav`, `main`, `section`, `footer`)
- **CSS** — colour variables for light/dark themes, Flexbox and Grid layouts, media queries for tablet (≤ 960px) and phone (≤ 760px)
- **JavaScript** — no libraries: mobile menu, theme toggle, active-section highlighting, copy-email button
- **AI tools** were used to draft code and copy; every line was reviewed, tested and edited by me

## Files

```
index.html                         page content and structure
style.css                          all styling and responsive rules
script.js                          interactive features
assets/Aphelele-Khambule-CV.pdf    downloadable CV
```

## Run locally

Open `index.html` in any browser. No install or build step needed.

## Deploy on GitHub Pages

1. Create a public repository called `portfolio` on GitHub.
2. Upload every file and the `assets` folder (keep the folder structure).
3. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, then **Save**.
4. After a minute or two the site is live at `https://ApheleleKhambule.github.io/portfolio`.
